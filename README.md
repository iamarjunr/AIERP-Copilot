

\# AIERP Copilot



AIERP Copilot is a portfolio project to develop a SaaS-style,

AI-powered Enterprise Resource Planning (ERP) system for

small and medium-sized businesses, initially focusing on

UAE business requirements.



\## Project Vision



Build a modular ERP platform that helps businesses manage

their daily operations through a unified system, with AI-powered

assistance for insights and decision support.



\## Technology Stack



\### Frontend

\- React

\- Vite

\- TypeScript

\- Tailwind CSS

\- Redux Toolkit

\- TanStack Query

\- Axios



\### Backend

\- ASP.NET Core Web API

\- C# / .NET 10

\- Entity Framework Core

\- PostgreSQL



\### AI Service

\- Python

\- AI / Machine Learning integrations



\### Testing

\- xUnit

\- Frontend testing tools



\## Architecture



The project follows a simple layered backend architecture

with a separate frontend and AI service.
